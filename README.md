# Flin RP Launcher Backend

Бесплатная замена PHP-скриптов с утерянного домена flin-rp.su, на Vercel.

## Деплой
1. Залей эту папку в отдельный GitHub-репозиторий
2. Зайди на vercel.com → New Project → Import from GitHub → выбери репозиторий
3. Deploy (никаких доп. настроек не нужно, Vercel сам увидит папку /api)
4. Получишь адрес вида `https://твой-проект.vercel.app`

## Дальше
1. Открой `api/config.js`, замени плейсхолдеры (`ЗАМЕНИ_НА...`) на реальные ссылки/чексуммы
2. В лаунчере (смали-код) замени домен `flin-rp.su` на адрес из шага 3 — см. инструкцию с патчем
3. Закоммить/запушь — Vercel передеплоит сам

## Эндпоинты
- `GET /api/cheakverapp` — проверка версии лаунчера (не будет предлагать апдейт, пока version <= 9)
- `GET /api/cheakurlapp` — данные о версии/ссылках на мод
- `GET /api/install?type_install=..&hash=..&ip=..&model=..` — лог установки (просто отдаёт OK)

## Большие файлы (мод, .apk)
Не клади их в этот репозиторий и не пытайся раздавать через Vercel — там лимиты на размер.
Заливай их в GitHub Releases (до 2ГБ на файл, бесплатно) отдельного репозитория,
а в `config.js` укажи прямые ссылки на них.
